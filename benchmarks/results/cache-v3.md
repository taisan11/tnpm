# レジストリキャッシュ v3：変更前後の比較

Measured: 2026-10-25T00:23:41.814Z

Apple M4 / macOS arm64 / Node v26.12.1。両方とも release ビルド、各15サンプル・warmup 2回、順序交互、並列数1、外れ値除外なし。
変更前バイナリには前回の依存グラフ連続配列化を含みます。今回はそこからの追加高速化です。

## 変更点

- v3 は本文と HTTP ポリシーに独立した共有文字列プールを持ち、同じキー・説明・license・数値表現などを1回だけ保存。
- オブジェクトは元のメンバー順＋キー順の番号索引。復元時に並べ替え用の配列を作らない。
- SemVer 順のバージョン索引を保存し、読み込み時の全件解析・ソートを廃止。
- 通常の依存取得は最新の適合バージョンだけ復元。peer 探索の候補全件取得は維持。
- `view FIELD...` は参照するルートキーだけ復元し、install は表示用 time / readme / 全バージョン名配列を復元しない。キャッシュには元の全情報を保存する。
- 新鮮なキャッシュで回答できる場合は HTTP client / TLS / proxy の初期化も省略。
- ファイルの偶発的な破損検出を FNV-1a 64 bit から XXH3-128 に変更。共有文字列プールは読み込み時に一度だけ UTF-8 検証し、各参照では範囲・文字境界を確認。tarball の SRI 検証は変更していない。
- v1 / v2 の互換読み込み・移行・フォールバックはなし。[バイナリ仕様](../../docs/cache-format.md)。

## キャッシュ容量

HTTP ポリシーを含む1ファイルのサイズです。時刻値の共有状態により実行ごとに少量変動します。

| バージョン数 | v2 (bytes) | v3 (bytes) | 削減 |
| ---: | ---: | ---: | ---: |
| 300 | 518,330 | 332,681 | 35.8% |
| 3,000 | 3,971,531 | 2,102,481 | 47.1% |

3,000バージョンの完全一致 view の内部計測では、cache_read が平均 4.318 → 0.282 ms、cache_resolve が 1.772 → 0.004 ms。後者には必要なフィールドだけを復元する効果も含み、汎用デコーダ単体の倍率ではありません。全体時間の主張には上の subprocess 時間を使います。

## 測定と検証の範囲

- 同じ合成 packument をローカル HTTP で配布。重複する説明・キー・license など、各バージョンの異なる URL、トップレベルの time / readme を含む。
- HOME / npmrc / キャッシュはバイナリごとに隔離。HTTP 件数をサーバーで計測し、各 warm 呼び出し0件、各304再検証1件、各 cold 生成の200全文取得1件を確認。
- offline 依存解決は、lockfile のない1依存プロジェクトで `install --package-lock-only --no-save --offline --ignore-scripts --json` を実行。通常 install 全体や3,000個のパッケージを配置する測定ではない。
- プロセス起動・JSON 出力読み取り・診断出力を含む。fixture 生成、warmup、キャッシュ削除、検証は計測外。OS のファイルキャッシュは warm。
- warm 表示・解決結果、cold 生成、HTTP 304 と本文再利用を確認。単体テストは文字列共有、順序・数値表現・重複キー、破損ヘッダー・索引・プール・UTF-8 境界・循環オフセット、各種範囲と peer 候補の全件取得を検証する。
- CLI テストでは、最小フィールドで作成したキャッシュからの全表示・投影結果がネットワーク取得と一致すること、fresh hit で HTTP client を初期化しないことも確認。
- この比較はキャッシュ形式だけを切り替えた単一要因実験ではなく、索引・問い合わせ経路・HTTP client の遅延初期化を含む変更全体。実パッケージ、cold network、tarball 展開、node_modules 配置、lifecycle script の倍率は示さない。
- 既存 lockfile を再利用してメタデータ取得を行わない install には、このレジストリ高速化の効果は基本的にない。

## 再現と生データ

```sh
node benchmarks/cache.mjs --before=target/tnpm-before-cache-v3 --samples=15 --output=benchmarks/results/cache-v3.json
```

`target/tnpm-before-cache-v3` は変更前の release バイナリ。再現にはこのバイナリ、または変更前ソースから作成した別のバイナリを指定してください。
[JSON レポート](cache-v3.json) に全サンプル・p50 / p99・内部 profile・HTTP 件数・バイナリ SHA-256・キャッシュ形式番号を保存しています。過去の測定結果は上書きしていません。
